How it works

01 Search

  • Type a prefix to find matching entries.
  • Tap a result, or use the arrow keys and Enter, to add it to your list.
  • Pressing Enter without selecting will select the first result if it exists. Otherwise it appends the input unchanged.
  • The quantity text box beside the search bar adds an optional quantity before the selected item.
  • Press Space or Enter in the quantity text box to move to the search bar. Press Backspace in an empty search bar to move back to the quantity text box.
  • Edit the saved list and append snapshots to a temporary buffer for preview or download.
  • Press Alt+C to toggle Clear after adding

02 Add

  • Add one entry directly to your dictionary.
  • Import many entries from a CSV file.
  • Optionally name the CSV column to parse. Otherwise the first column is used.
  • Review every parsed entry in the preview before confirming the import.

03 Delete

  • Search your existing entries and delete a single match.
  • Clear the entire dictionary with the delete-all confirmation.
